Layout System

Case Study Reading Grid

The case body uses a stable 2-column grid: a fixed 240px sidebar column for the vertical index TOC, and a 1fr content column. The fixed pixel sidebar guarantees its left edge always matches the showcase image's left edge — no fractional drift on different viewport widths. .case-content is capped at 68ch with margin-right: auto so any leftover 1fr space sits gracefully on the right.

CSS Spec 
/* Outer wrapper — zero horizontal padding */
.case-body {
  padding: var(--space-16) 0 var(--space-20);
}

/* 2-column grid — desktop only */
.case-layout {
  display: grid;
  grid-template-columns: 1fr; /* mobile: stacked */
  gap: var(--space-12);
  align-items: start;
}
@media (min-width: 1024px) {
  .case-layout {
    grid-template-columns: 240px 1fr;
    column-gap: var(--space-12);
  }
}

/* Reading column — comfortable line length, left-aligned */
.case-content {
  display: flex;
  flex-direction: column;
  min-width: 0;
  max-width: 68ch;
  margin-right: auto;
}

lightbox

Modal de zoom full-screen. Shell .lightbox cobre o viewport via position:fixed. Estado fechado: opacity:0; visibility:hidden; scale(0.92). Estado aberto (.is-open): opacity:1; scale(1). JS deve adicionar .is-open para abrir e .is-zoomable nas imagens que o ativam. prefers-reduced-motion remove o scale, mantém o fade.

Tokens de classe

  • .is-zoomable — cursor zoom-in; JS hook para abrir o lightbox
  • .lightbox — shell fixo, oculto por padrão
  • .lightbox.is-open — estado visível (toggle via JS)
  • .lightbox__backdrop — sobreposição frosted escura
  • .lightbox__panel — painel animado: imagem + legenda + botão fechar
  • .lightbox__img — max 82vh
  • .lightbox__caption — legenda centralizada, max 60ch
  • .lightbox__close — botão circular, canto superior direito do painel

<!-- Imagem que aciona o lightbox -->

cs-figure--full-bleed

Modificador que rompe uma <figure> para cobrir 100vw usando margens negativas calculadas. O cálculo é acoplado às constantes de layout: sidebar 240px · gutter mínimo 80px (--space-20) · gap 48px · coluna de conteúdo 68ch. Não altere sem recalcular os três breakpoints.

Margens por breakpoint

  • <768px: margin-left: calc(-1 × var(--space-6))
  • 768–1023px: margin-left: calc(34ch − 50vw)
  • ≥1024px: margin-left: calc(128px − 50vw)
