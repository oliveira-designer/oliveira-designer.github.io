Typography Scale

Fluid sizes use clamp(). Two families only: Geist (geometric sans) drives all display headings (--font-display) and technical micro-labels (--font-mono); Plus Jakarta Sans handles body copy. Mono-style labels simulate the technical register with text-transform: uppercase + letter-spacing: 0.08em — no typewriter face required.

Layout System

Case Study Reading Grid

The case body uses a stable 2-column grid: a fixed 240px sidebar column for the vertical index TOC, and a 1fr content column. The fixed pixel sidebar guarantees its left edge always matches the showcase image's left edge — no fractional drift on different viewport widths. .case-content is capped at 68ch with margin-right: auto so any leftover 1fr space sits gracefully on the right.

CSS Spec 
/* Outer wrapper — zero horizontal padding */
.case-body {
  padding: var(--space-16) 0 var(--space-20);
}

/* 2-column grid — desktop only */
.case-layout {
  display: grid;
  grid-template-columns: 1fr; /* mobile: stacked */
  gap: var(--space-12);
  align-items: start;
}
@media (min-width: 1024px) {
  .case-layout {
    grid-template-columns: 240px 1fr;
    column-gap: var(--space-12);
  }
}

/* Reading column — comfortable line length, left-aligned */
.case-content {
  display: flex;
  flex-direction: column;
  min-width: 0;
  max-width: 68ch;
  margin-right: auto;
}
