Textarea

Multi-line text field with a label and helper text. Same states and values as Input, 96px high, resizable vertically.

When to use

  • Free text longer than a line, such as a message.

Accessibility

Every field needs a visible label tied with for and id, and the helper text is linked with aria-describedby. The Error state is not only a color: the helper text carries the message and the control has aria-invalid="true".
