Radio

20px radio with a label and optional helper text. Unselected and selected, in five states. Group radios in a fieldset with a legend.

Accessibility

A real radio: the arrow keys move inside a group that shares a name. Group the radios in a fieldset with a legend. The Error state is not only a color: the helper text carries the message.
