Toast

Floating, passing feedback in four types: Success, Warning, Error and Info (a neutral message uses Info). Message, optional description, action and dismiss. The positioning region and the timing are not part of this component.

When to use

  • Short feedback after an action, such as "Saved" or "Message sent".

Variants and tokens

Accessibility

Error uses role="alert", Warning, Info and Success use role="status". The dismiss button needs an accessible name, and the type never relies on color alone: the glyph and the text say it too. Live-region roles (alert, status) announce content that is inserted into the page. An Alert already present when the page loads needs no role to be read: apply the role when you inject the message. MDN: developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/alert_role and .../status_role.
