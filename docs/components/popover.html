Popover

A floating panel of 280px anchored to a trigger, with an optional title and free content (text, links, a small control). It opens on click, closes on a click outside, does not block the page and has no arrow.

When to use

  • Extra context tied to the element that opened it.
  • A small control or a link next to its trigger: unlike a Tooltip, it can have interaction and opens on click.
  • Content that can hold text, links or a small control (the Figma text says free content).

When not to use

  • A decision that must be taken first: unlike a Popover, a Modal blocks the screen.
  • A list of actions or options: use a Menu.
  • A short label on hover or focus: use a Tooltip.

Anatomy

  • Trigger: any button with aria-expanded and aria-controls.
  • Panel: 280 wide, border, radius 12, Shadow/md, layer 300. No arrow: only the Tooltip has one (the Menu panel has none either).
  • Title (optional): Body/SemiBold/body-sm semibold.
  • Body: Body/Regular/body-sm, free content.

States

Popover states, what changes in each and the tokens involved
State What changes Tokens
Closed The panel has the hidden attribute and the trigger has aria-expanded="false". none
Open The panel shows below the trigger, aligned to its start, 8px away. The trigger has aria-expanded="true". --z-popover --shadow-md --space-2
Flipped When it does not fit below the trigger it opens above (only when there is room above). Code addition beyond the Figma text: near the right edge it aligns to the end of the trigger. .popover--above .popover--end

Keyboard and ARIA

Popover keyboard interaction
Key Action
Enter and Space On the trigger: open or close the panel.
Tab The panel follows the trigger in the DOM, so Tab goes into it. When the focus leaves the panel, it closes.
Escape Closes the panel and returns the focus to the trigger. It does not close a Modal that contains the Popover.
  • The trigger has aria-expanded and aria-controls.
  • The panel has no role when it holds text only: the trigger state is enough.
  • When the panel holds interactive content, use role="dialog" without aria-modal and name it with aria-labelledby (the title). It is not role="menu".
  • The focus is not trapped and the page is not inert.

Classes and tokens

Popover classes, what each is for and the tokens its rule uses
Class Used for Tokens
.popover-anchor Wrapper of the trigger and the panel, the panel is placed against it. none
.popover The panel: 280 wide, border, radius 12, Shadow/md, layer 300. --space-2 --z-popover --space-4 --font-body --color-bg --border-width-normal --color-border --radius-md --shadow-md
.popover--above Opens above the trigger (added by js/popover.js when there is no room below). --space-2
.popover--end Aligns the panel to the end of the trigger (added by js/popover.js near the right edge). none
.popover__title The optional title. --fs-body-sm --color-text-1
.popover__body The supporting text. --fs-body-sm --color-text-2
