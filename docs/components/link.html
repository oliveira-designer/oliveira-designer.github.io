Link

Summary

Text link for navigation and low emphasis actions. Two sizes and four states. Distinguished from surrounding text by underline.

8 Figma variants 8 in code 1 Atencao 0 Informativo 2 known gaps

When to use and when not to use

When to use

  • Navigation to another page, section or resource.
  • Low emphasis actions.

When not to use

  • The primary action of a screen: use Button.
  • Triggering actions that change data: use Button.

Anatomy

  • Container (Medium): height 21, textSize 13, decoration underline.
  • Container (Small): height 18, textSize 11, decoration underline.
  • Label: text property "Label", default "Link".

How states are implemented

  • hover: pseudo-class .link:hover: weight 700, colour unchanged (the global a:hover colour is overridden by .link:hover)
  • focus: .link:focus-visible: weight 700 and a square 2px outline with 2px offset (--focus-ring-width, --focus-ring-gap)
  • disabled: .link[aria-disabled="true"]: --color-text-disabled-default, weight 400, not focusable when the anchor has no href

Live examples

Real markup with the real classes from css/hope.css (sources in css/components/). Hover and focus are not simulated: interact with each element (hover it, tab to it). Hover widens the text by about 1px because the weight goes from 400 to 700: that small layout shift is as specified in Figma. The disabled link is an anchor without href plus aria-disabled="true", so it is not focusable.

  • Distinguishable from text: The link colour is the body text colour, so the underline is what separates a link from plain text.
  • Target size: Medium is 21 high and Small is 18 high, below the 24 by 24 of 2.5.8 Target Size (Minimum, AA). Inline links inside a sentence are covered by the inline exception. Stand-alone links need spacing to meet it.
  • Naming: Every link needs a clear destination in its own text.
