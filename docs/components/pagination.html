Pagination

Page numbers, Previous and Next as 36 by 36 items with radius 12, and a non-interactive ellipsis for long sequences. The current page is a dark fill.

When to use

  • A long list split into pages, with the number of pages known.
  • Use the ellipsis to collapse a long sequence: for example 1, ..., 4, 5, 6, ..., 20.

Accessibility

A nav with aria-label="Pagination" containing a ul of li. Disabled Previous on the first page and Next on the last: a link with aria-disabled="true" and no href, so it is not focusable and cannot be activated (the same approach as the Hope Link). The Ellipsis is a decorative span with aria-hidden, not focusable. Tabs, Pagination and Menu mark the current item in three different ways on purpose: Tabs with a bottom line and text color, Pagination with a dark fill, Menu with a light fill, SemiBold text and a check.
