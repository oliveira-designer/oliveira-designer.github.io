Breadcrumb

The path to the current page as a list of links, ending in the current page as plain text. 13px text with a 14px caret between items; the last item has no separator. On narrow screens the middle levels collapse into an ellipsis button that opens a Menu.

When to use

  • A hierarchy with two or more levels, so the user can climb back up.
  • A long path on a narrow screen: collapse the middle levels into the Ellipsis. The path always shows the first level, the ellipsis and the current page, and the hidden levels open in a Menu.

States

Breadcrumb states, what changes in each and the tokens involved
State What changes Tokens
Link, default Text/Default/Secondary, Regular, no underline. --color-text-2
Link, hover Text goes to Text/Default/Default. --color-text-1
Link, focus Text/Default/Default and a ring of 2px with a 2px gap around the label only, 40 by 29, no radius. --color-text-1 --focus-ring-width --focus-ring-gap --color-border-focus-ring
Current Medium, Text/Default/Default, not a link and never focusable. --color-text-1
Ellipsis, default A button with the DotsThree icon at 16px in the Icon/Color Secondary mode, followed by the optional separator. --icon-color-secondary
Ellipsis, hover The icon goes to the Icon/Color Default mode. No fill. --icon-color-default
Ellipsis, focus The icon in the Default mode and a square ring (radius 0) around the icon only, 24 by 24: 2px stroke, 2px gap, Border/Utilities/Focus Ring. --icon-color-default --focus-ring-width --focus-ring-gap --color-border-focus-ring
Ellipsis, menu open The Menu panel hangs below the button, aligned to its start, 8px away, on the popover layer (300). The items are the hidden levels, as links. --space-2 --z-popover

Positioning

  • Default placement is below the trigger and aligned to its start (data-placement="bottom", data-align="start"). The offset between trigger and panel is 8px (--space-2), read from the token.
  • The Ellipsis panel is the Menu panel: it keeps its CSS position (absolute, below the button, 8px away) and its 238px width, and has data-placement="bottom" so js/position.js flips it above near the bottom edge and keeps it inside the viewport.
  • Flip: if the preferred side does not fit in the viewport and the opposite side does, the panel goes to the opposite side. If neither fits, it stays on the side with more room.
  • Cross axis: if the panel would leave the viewport, the alignment flips (start to end) when that makes it fit; otherwise the panel is shifted to stay inside, 16px (--space-4) from the edge.
  • The position is calculated when the panel opens, on window resize and on a scroll of any ancestor while it is open. The listeners are removed on close. Positioning never moves the focus and adds no animation.
  • Layering is not changed: the panel stays in normal flow layering on its --z-* layer, so a Popover or Menu never covers a Toast (layer 500). Native CSS anchor positioning and the Popover API are not used (see the gap position-native-anchor-future).

Keyboard and ARIA

Breadcrumb keyboard interaction
Key Action
Tab Moves through the links and the ellipsis button in path order. The current page is not a tab stop.
Enter or Space (on the ellipsis) Opens the Menu and moves the focus to its first item.
Arrow Down or Arrow Up (on the ellipsis) Opens the Menu, on the first or the last item.
Arrow Down, Arrow Up, Home, End (in the Menu) Move between the hidden levels, as in the Menu.
Enter (on a level) Follows the link.
Escape Closes the Menu and returns the focus to the ellipsis.
Tab (in the Menu) Closes the Menu.
  • The path is a nav with aria-label="Breadcrumb" containing an ordered list. The ellipsis is a button, not a link: it has aria-haspopup="menu", aria-expanded and aria-controls, and the accessible name "Show path". The icon is decorative (aria-hidden).
  • The panel is a Menu (role="menu") with the hidden levels as links with role="menuitem". The current page keeps aria-current="page". The first level and the current page always stay visible.

Accessibility

A nav with aria-label="Breadcrumb" containing an ordered list; each item is an li. The separator is decorative: aria-hidden, so a screen reader reads the list as items, not as carets. The last item must not render a separator in code. The ellipsis is a button with a Menu, not a link: it stands for the hidden middle levels, and the current page keeps aria-current="page". Collapse is decided by the author in the markup, there is no automatic collapse by width.
