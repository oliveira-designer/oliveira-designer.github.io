Button

Figma content from 2026-11-19 (v0.1), code notes from 2026-11-19. Generated by npm run docs:components; the data files in docs/data/ are the source.

Summary

Triggers actions and decisions. Six styles, two sizes, optional leading and trailing icon. Icon Button is a separate 44 by 44 component for icon-only actions.

28 Figma variants (+ 8 Icon Button) 28 in code (Icon Button 0) 0 Atencao 2 Informativo 5 known gaps

When to use and when not to use

When to use

  • Primary: the main action on the screen.
  • Secondary: alternative actions.
  • Ghost: lower visual weight.
  • Accent: emphasis.
  • Inverse: on dark backgrounds.
  • Destructive: irreversible or dangerous actions, such as delete or cancel.

When not to use

  • Navigation to another page or section: use Link.

Anatomy

  • Container (Medium): height 45, radius Radius/radius-md (12), padding Spacing/space-3 vertical, Spacing/space-5 horizontal, gap Spacing/space-2, labelSize 13.
  • Container (Small): height 37, radius Radius/radius-pill, padding Spacing/space-2 vertical, Spacing/space-4 horizontal, gap Spacing/space-2, labelSize 13.
  • Label: text property "Label", default "View case study".
  • Optional icon: property "Show icon L / Icon L" (boolean + instance swap), default true.
  • Optional icon: property "Show icon R / Icon R" (boolean + instance swap), default true.
  • Icon Button (separate component): a single icon in a 44 by 44 pill, see the Icon Button section.

Parts are read from the Figma properties and layout only. Nothing here is inferred.

How states are implemented

  • hover: Pseudo-class :hover on each style class (.btn--primary:hover, .btn--secondary:hover, .btn--accent:hover, .btn--ghost:hover, .btn--inverse:hover, .btn--destructive:hover, .btn--ghost-sm:hover).
  • focus: Pseudo-class .btn:focus-visible: outline var(--focus-ring-width) solid var(--color-border-focus-ring) with offset var(--focus-ring-gap), one rule shared by every style. No state class.
  • disabled: .btn.btn:disabled and .btn.btn[aria-disabled="true"] (specificity 0,3,0, so it also beats :hover). Secondary, Ghost and Small Ghost have their own disabled rules (no fill). Background, text and border use the disabled tokens. No state class.

  • Target size: Medium is 45 high and Icon Button is 44 by 44, which meets 2.5.5 Target Size (Enhanced, AAA). Small is 37 high, which meets 2.5.8 Target Size (Minimum, AA, 24 by 24) but not 2.5.5.
  • Focus: In Figma the ring is a separate layer: no fill, 2px inside stroke bound to Border/Utilities/Focus Ring and Stroke/focus, with a 2px transparent gap (Stroke/focus-gap); square where the component radius is 0. In code it is an outline of 2px (--focus-ring-width) with a 2px offset (--focus-ring-gap) on every style.
  • Naming: Icon Button has no visible text. In code it needs an accessible name (aria-label), as the Figma description states.
  • Disabled state: Disabled uses the disabled tokens, not opacity.
