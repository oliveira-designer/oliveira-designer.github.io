Button

Triggers actions and decisions. Six styles, two sizes, optional leading and trailing icon. Icon Button is a separate 44 by 44 component for icon-only actions.

Live example

HTML 
<button class="btn btn--primary" type="button">Primary</button>
<button class="btn btn--primary" type="button" disabled>Primary Disabled</button>
<button class="btn btn--secondary" type="button">Secondary</button>
<button class="btn btn--secondary" type="button" disabled>Secondary Disabled</button>
<button class="btn btn--ghost" type="button">Ghost</button>
<button class="btn btn--ghost" type="button" disabled>Ghost Disabled</button>
<button class="btn btn--ghost-sm" type="button">Ghost Small</button>
<button class="btn btn--ghost-sm" type="button" disabled>Ghost Small Disabled</button>
<button class="btn btn--inverse" type="button">Inverse</button>
<button class="btn btn--inverse" type="button" disabled>Inverse Disabled</button>
<button class="btn btn--accent" type="button">Accent</button>
<button class="btn btn--accent" type="button" disabled>Accent Disabled</button>
<button class="btn btn--destructive" type="button">Destructive</button>
<button class="btn btn--destructive" type="button" disabled>Destructive Disabled</button>

When to use

  • Primary: the main action on the screen.
  • Secondary: alternative actions.
  • Ghost: lower visual weight.
  • Accent: emphasis.
  • Inverse: on dark backgrounds.
  • Destructive: irreversible or dangerous actions, such as delete or cancel.

Accessibility

In Figma the ring is a separate layer: no fill, 2px inside stroke bound to Border/Utilities/Focus Ring and Stroke/focus, with a 2px transparent gap (Stroke/focus-gap); square where the component radius is 0. In code it is an outline of 2px (--focus-ring-width) with a 2px offset (--focus-ring-gap) on every style.
