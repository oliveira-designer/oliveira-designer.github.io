Tag

A pill of 28px that can be removed: a label and an optional X. The whole Tag is the button. It is not a Badge, which is static and shows a status.

When to use

  • A removable value, such as an applied filter or a chosen option.
  • The whole Tag is the button; the X is a visual cue inside it.
  • If the Tag is not interactive, use a Badge (the Figma text).

When not to use

  • A status or a count that does not change: use a Badge.
  • A navigation link: use a Link.

Anatomy

  • Pill: 28 high, radius pill, 1px border, padding 0 12, gap 4.
  • Label: Body/Medium/body-sm medium, Text/Default/Default.
  • Dismiss (optional): X 14px in the Icon/Color Secondary mode, a visual cue and not a second button.

States

Tag states, what changes in each and the tokens involved
State What changes Tokens
Default Fill Background/Default/Secondary, border Border/Default/Default. --color-bg-alt --color-border
Hover Fill goes to Border/Default/Default. --color-border
Focus Ring 2px with 2px gap around the whole Tag, following the pill. --focus-ring-width --focus-ring-gap --color-border-focus-ring
Disabled Fill, border, text and icon from the Disabled tokens, no opacity. Uses the disabled attribute. --color-bg-disabled-default --color-border-disabled-default --color-text-disabled-default --icon-color-disabled

Keyboard and ARIA

Tag keyboard interaction
Key Action
Enter and Space Remove the Tag (the whole Tag is the button).
Delete and Backspace Remove the Tag when it has the focus (the Figma text).
Tab Moves between Tags. After one is removed, the focus goes to the next Tag, else the previous one, else the parent.
  • The Tag is a <button type="button">; the X is aria-hidden.
  • The accessible name is the visible label plus the action, for example aria-label="Remove filter Design".
  • js/tag.js fires a cancelable "hope:tag-remove" event before removing it, so the application can update its state.
  • Disabled uses the disabled attribute.
