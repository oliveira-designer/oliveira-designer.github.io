Modal

A dialog of 480px over a scrim, for one decision: a title, a close button, a short body and an optional footer with the actions. It blocks the page until the person decides.

Live example

Publicar alterações?

As alterações ficam visíveis para toda a equipe. Você pode desfazer a publicação depois.

Excluir projeto?

O projeto e todos os arquivos dele serão apagados. Essa ação não pode ser desfeita.

When to use

  • A short decision that must be taken before the person goes on: confirm, cancel, choose.
  • Keep it short and about a single decision (the Figma text).
  • A destructive confirmation uses the destructive Button as the main action.

When not to use

  • Extra context tied to an element, or a small control: use a Popover, which does not block the page.
  • A list of actions on an object: use a Menu.
  • A long form or a flow with several steps: use a page.
  • Zooming an image: use a Lightbox.

Anatomy

  • Scrim: a full-screen layer behind the panel (--color-bg-scrim). A click on it does not close the Modal.
  • Panel: the dialog, 480 wide, centered, with a border, a radius of 16 and Shadow/lg.
  • Header: the title (Heading/H3) and the close button with a 20px X icon.
  • Body: the supporting text (Body/Regular/body-sm, Text/Default/Secondary).
  • Footer (optional): right aligned, a Secondary and a Primary (or Destructive) Button.

States

Modal states, what changes in each and the tokens involved
State What changes Tokens
Closed The dialog and the scrim have the hidden attribute. Nothing is rendered. none
Open The scrim covers the page, the dialog is centered, the page behind is inert and its scroll is locked. --color-bg-scrim --z-modal-scrim --z-modal
Close button, hover The X goes from the Secondary to the Default icon color. Figma draws no hover. --icon-color-secondary --icon-color-default
Close button, focus The shared ring (2px, 2px gap) following the pill radius. Figma draws no focus. --focus-ring-width --focus-ring-gap --color-border-focus-ring

Keyboard and ARIA

Modal keyboard interaction
Key Action
Tab and Shift+Tab Move through the controls of the dialog. The focus wraps from the last to the first and cannot leave the dialog.
Escape Closes the Modal and returns the focus to the trigger.
Enter and Space Activate the focused button (close, Cancel, Confirm).
  • The panel has role="dialog" and aria-modal="true".
  • aria-labelledby points at the title and aria-describedby at the body.
  • The close button has an accessible name (aria-label) because it holds only an icon.
  • The focus moves into the dialog on open (to the first control, or to the element with data-modal-initial-focus) and returns to the trigger on close.
  • The page behind is inert and the scroll is locked while the Modal is open.

Classes and tokens

Modal classes, what each is for and the tokens its rule uses
Class Used for Tokens
.modal-scrim The full-screen scrim behind the panel, layer 100. Created by js/modal.js. --z-modal-scrim --color-bg-scrim
.modal The dialog panel: 480 wide, border, radius, shadow, layer 200. --z-modal --space-4 --space-6 --font-body --color-bg --border-width-normal --color-border --radius-lg --shadow-lg
.modal__header Row with the title and the close button. --space-3
.modal__title The title, Heading/H3. --font-display --fs-h3 --color-text-1
.modal__close The 20px X button (needs an aria-label). --space-5 --icon-color-secondary --radius-pill --duration-normal --ease-out
.modal__body The supporting text. --fs-body-sm --color-text-2
.modal__footer Right aligned row of actions. --space-3

Code notes

Modal code notes, the status of each and the detail
Note Status Detail
modal-footer-button-width documented Figma shows both footer buttons 184 wide. That is a fixed width on the instances, not a Button rule, so in code the buttons hug their content. Pending decision.
modal-close-states documented Figma draws no Hover and no Focus for the close button. Focus follows the Icon Button pattern (2px ring with 2px gap, pill radius). Hover uses the Ghost Icon Button pattern (Icon/Color Secondary to Default). Both are borrowed, not drawn in Figma.
modal-narrow-width documented Figma does not define the panel on narrow screens. The panel is 480 wide and keeps a margin of 24px (--space-6, the mobile page gutter) on each side: max-width calc(100% - 2 * --space-6). When the content is taller than the viewport, the panel scrolls.
modal-no-motion documented Figma defines no motion, so the Modal opens and closes without animation. There is nothing to remove under prefers-reduced-motion.
modal-native-dialog inference The Modal uses the same approach as the Lightbox (the hidden attribute, a script for the focus trap, Escape, inert and scroll lock), not the native <dialog> element. Moving to <dialog> is an open decision: the top layer ignores z-index, so the Toast (500) would stay under an open Modal unless the Toast also moves to the top layer.
modal-toast-inert inference While a Modal is open the rest of the page is inert. A .toast and any element with data-modal-keep stay active so a notification still reaches the person. The Toast layer (500) is above the Modal (200).
modal-dark-panel-contrast measured In Dark the panel (Background/Default/Default) is 1.16:1 against the scrim over the page and its border is 1.49:1. In Light they are 3.64 and 2.82. The shadow does not count as a boundary for WCAG 1.4.11. Implemented as in Figma; the decision is pending.
modal-scrim-name documented The Figma Info text said the scrim was "Overlay" by mistake. It is Background/Utilities/Scrim (--color-bg-scrim).
