Lightbox

A full-screen image viewer: a dark scrim with a blur, an image of up to 960px, an optional caption and a close button (the Lightbox close component) at the top-right corner of the image. It sits at the same layer as the Modal.

Live example

HTML 
<figure>
  <img data-lightbox src="../../images/case-thumbnails/dotz-thumb-light.png" alt="Miniatura do estudo de caso Dotz, com a tela inicial do aplicativo" width="320">
  <figcaption>Miniatura do estudo de caso Dotz.</figcaption>
</figure>

When to use

  • Looking at one image closely: screenshots, diagrams and case study figures.
  • The caption comes from the figcaption of the image.
  • The image needs a meaningful alt: the viewer reuses it.

When not to use

  • A decision or a form: use a Modal.
  • A gallery with navigation between images: it is not designed (Figma has one image).
  • Decorative images: do not make them zoomable.

Anatomy

  • Overlay: full screen, Scrim Strong plus a background blur (Figma 12, CSS blur(6px): the Figma radius is double the CSS radius), padding 24.
  • Panel: the image and the optional caption, 16 apart. The panel has no root border.
  • Image: up to 960 wide, radius 16, Shadow/lg.
  • Caption: Body/Regular/body-sm, white at 55%, centered, up to 520 wide.
  • Close button (Lightbox close): 36 by 36 glass circle at the top-right corner of the image, 40px above it, with a white X of 20px.

States

Lightbox states, what changes in each and the tokens involved
State What changes Tokens
Closed The overlay has the hidden attribute. none
Open The overlay fades in, the panel scales in, the page behind is inert and its scroll is locked. --color-bg-scrim-strong --z-modal --duration-slow
Close button, hover Glass fill from 12% to 22%, glass edge from 18% to 32%, X from 80% to 100% (Figma Lightbox close, Hover). --color-cloud
Close button, focus Default plus a ring of 2px with a 2px gap in Border/Accent/Default (Solar), 44 by 44 around the circle, radius 22 (Figma Lightbox close, Focus). --focus-ring-width --focus-ring-gap --color-border-accent-default

Keyboard and ARIA

Lightbox keyboard interaction
Key Action
Enter and Space On a zoomable image: open the Lightbox. On the close button: close it.
Escape Closes the Lightbox and returns the focus to the image.
Tab The focus stays on the close button (the only control).
  • The overlay has role="dialog", aria-modal="true" and aria-label="Image preview".
  • A zoomable image has role="button", tabindex="0" and an aria-label that starts with "Zoom in".
  • The close button has an accessible name (aria-label). It is the Lightbox close component: Default, Hover and Focus, no Disabled.
  • The alt of the image is reused in the viewer; the caption is the text of the figcaption.
  • The page behind is inert and the scroll is locked while it is open.

Classes and tokens

Lightbox classes, what each is for and the tokens its rule uses
Class Used for Tokens
.lightbox The overlay shell, layer 200. Built by js/lightbox.js. --z-modal --space-6
.lightbox__backdrop Scrim Strong plus the 12px blur. --color-bg-scrim-strong
.lightbox__panel Image and caption, up to 960 wide. --space-4 --duration-slower --ease-out
.lightbox__media Hugs the image, so the close button sits at the corner of the image. none
.lightbox__img The image, radius 16 and Shadow/lg. --space-6 --space-10 --radius-lg --shadow-lg
.lightbox__caption The caption, from the figcaption. --font-body --fs-body-sm --color-cloud
.lightbox__close The 36px close button. --space-10 --color-cloud --border-width-normal --radius-pill

Code notes

Lightbox code notes, the status of each and the detail
Note Status Detail
lightbox-close-icon-color documented Decided in Figma (Lightbox close, 2026-11-24): the X uses the primitive white in BOTH themes and does not follow Icon/Color, because the Lightbox scrim is dark in both. Icon/Color Neutral would turn ink in Dark. Intentional; a dark mode era item: reevaluate when dark mode lands.
lightbox-blur documented The Figma effect is a raw background blur of radius 12 (not a style, no token). The CSS uses blur(6px): the Figma radius is double the CSS radius, so Figma 12 renders as CSS blur(6px), and Figma's own code export gives blur(6px). The source of this equivalence is Figma forum answers on blur in Dev Mode, not the official docs. Accepted divergence in docs/data/accepted-divergences.json (decided by Renan, 2026-11-24). No blur token matches, so the value is a literal: open item.
lightbox-scrim-dark documented Known accepted divergence D-05: the Dark value of Scrim Strong is #000000e0 in Figma and #0d0d0fe0 in the CSS (the same value in both themes). Not changed in this release.
lightbox-narrow documented The image height is limited to the viewport minus the overlay padding, the 40px of the close button on each side and room for a caption of three lines, so the close button always stays inside the viewport. Figma does not define narrow screens.
lightbox-no-gallery documented Figma has one image and no previous or next controls. They are not built.
lightbox-close-contrast measured The close fill is 1.46:1 and the stroke 1.79:1 against the scrim in Light (1.37 and 1.69 in Dark). The X, which identifies the button, is 10.2:1 and 13.04:1. The ring is 9.02:1 and 12.08:1.
