Icon Button

A 44 by 44 round button with one 24px icon, in Primary and Ghost, with Default, Hover, Focus and Disabled. It has no visible text, so it needs an accessible name.

When to use

  • A compact action whose icon is well known, such as add or close.
  • Primary for the one main action of a group, Ghost for secondary actions.

Variants and tokens

Accessibility

A native button: Tab reaches it, Enter and Space activate it. The icon is decorative. The accessible name says what the button does ("Add item"), never the name of the icon.
