Tooltip

Short text hint on a dark bubble with an arrow, in four placements: Top, Bottom, Left and Right. The bubble and the arrow are one piece. The docs demos place it against a trigger with js/position.js (positioned, trigger not coded); showing it on hover and focus is a separate, open item.

When to use

  • A short label that explains an icon-only control, such as an Icon Button.
  • A hint that repeats something the page already says: the tooltip is never the only place for essential information.

Positioning

  • Four placements, the names of the Figma set: data-placement="top|bottom|left|right". The Tooltip keeps its default of top, centered on the trigger (data-align="center"). The offset to the trigger is 8px (--space-2), a code value: Figma does not define a distance.
  • Flip: if the preferred side does not fit in the viewport and the opposite side does, the tooltip goes to the opposite side and the class tooltip--top|bottom|left|right follows, so the arrow keeps pointing at the trigger. If neither fits, it stays on the side with more room.
  • Cross axis: a centered tooltip that would leave the viewport is shifted to stay 16px (--space-4) inside (start and end alignments flip first). The arrow stays centered on the bubble, so after a shift it no longer points at the center of the trigger (see tooltip-arrow-shift).
  • Today this is wired in the docs demos only (data-anchor names the trigger). The tooltip is positioned, the trigger is not coded: showing and hiding on hover and focus, the delay and WCAG 1.4.13 stay open (tooltip-hover-focus-behavior).

The Flip demo trigger is pinned to the bottom right corner of the viewport (it stays there while you scroll) and its tooltip prefers the bottom: it flips to the top and, being centered, is shifted left to stay inside.

Accessibility

The trigger points to the tooltip with aria-describedby and the tooltip has role="tooltip". The text is a hint, not the only name of the control: an icon-only control keeps its own accessible name (aria-label). A tooltip does not appear on touch, so it never holds the only way to reach essential information.
