Component

Badge

Figma content from 2026-11-19 (v0.1), code notes from 2026-11-19. Generated by npm run docs:components; the data files in docs/data/ are the source.

Summary

Compact, non-interactive label for themes, status and highlights. Brand styles (Ancora, Solar), semantic styles (Success, Danger) and Neutral.

5 Figma variants 4 in code 0 Atencao 3 Informativo 1 known gaps

When to use and when not to use

When to use

  • Ancora: technical categories.
  • Solar: highlights and milestones.
  • Success: positive status.
  • Neutral: discreet labels, including content under construction (Draft was removed on 2026-11-20).
  • Danger: error or urgency states.

When not to use

  • Anything interactive: use Tag (Tag exists in Figma Core, not in code).

Anatomy

  • Container (all): height 29, radius Radius/radius-pill, padding Spacing/space-1 vertical, Spacing/space-3 horizontal, text Body/Medium/body-sm medium, Plus Jakarta Sans Medium, 13, original case.
  • Label: text property "Label", default "Product Strategy".

Parts are read from the Figma properties and layout only. Nothing here is inferred.
