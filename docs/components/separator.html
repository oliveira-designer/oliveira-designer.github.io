Separator

Figma content from 2026-11-21 (v0.2), code notes from 2026-11-21. Generated by npm run docs:components; the data files in docs/data/ are the source.

Summary

Decorative horizontal rule that separates blocks of content. One variant, no states, no navigation function.

1 Figma variants 1 in code 0 Atencao 0 Informativo 0 known gaps

When to use and when not to use

When to use

  • Dividing groups of content inside a card, list or section when spacing alone is not enough.

When not to use

  • Structure that assistive technology must announce: use headings and landmarks.
  • A vertical divider: Figma has no vertical variant.

Anatomy

  • Container (all): height 1, width 100 in the Figma specimen, full container width in CSS, border Border/Default/Default.

Parts are read from the Figma properties and layout only. Nothing here is inferred.

Live examples

Real markup with the real class from css/hope.css (sources in css/components/). The line is decorative, so the markup is an hr hidden from assistive technology with aria-hidden="true": it carries no meaning and has no navigation function. A native hr keeps its thematic-break meaning when the CSS is missing, and the hiding is what makes it decorative. It is full width of its container; the 100 px width in Figma is only the specimen.
