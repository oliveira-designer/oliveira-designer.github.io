Table

Data table for comparing records across a few columns. A bordered wrapper with an optional caption, header cells, row headers and data cells. No sorting, selection, row hover or sticky header in this version.

When to use

  • Comparing several records across the same attributes, such as components and their variant counts.
  • Numeric columns, aligned to the end so digits line up.

Markup contract

  • Wrapper: a div with role region, aria-labelledby pointing at the caption id, and tabindex 0. The wrapper is always focusable so keyboard users can scroll it; there is no script that toggles it.
  • Inside the wrapper: a table with a caption (first child), thead, and tbody.
  • Header cells are th with scope col. Row headers are th with scope row. Data cells are td. No rowspan or colspan.
  • A numeric column puts the end modifier on its header cell and on every cell of that column.
  • Do not hide the caption with display or visibility. Use the hidden caption modifier instead.
  • Interactive elements inside cells need their own unique accessible names.

Accessibility

The wrapper is a focusable region named by the caption (role region, aria-labelledby, tabindex 0), so keyboard users can scroll a wide table. Header cells use scope col and row headers scope row; rowspan and colspan are not supported. Interactive elements inside cells need their own unique accessible names.
