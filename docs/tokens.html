Design tokens

235 custom properties from css/tokens.css, generated by npm run docs:tokens. Light and Dark are the computed values in the browser, so alias chains are already resolved. Figma is canonical for values: the Figma column comes from docs/data/figma-tokens.json (Figma Foundation, read 2026-11-25, 177 tokens).

Figma comparison summary

Mismatches are information for the divergence report, not build errors. Colors are compared as lowercase #rrggbbaa with a tolerance of 1/255 on alpha, lengths as px numbers (rem converted with a root of 16px: browser default: no html or :root font-size in css/*.css). Font sizes in clamp() compare the max to Desktop and the min to Mobile. --border-* compare the width part only; shadow colors compare the first layer.

Reading this page

Dark column: a muted value means the token has no dark override and simply inherits the Light value.

Reduced transparency: four tokens (--blur-glass, --color-material-bg, --color-material-border, --color-material-border-hover) are redefined under prefers-reduced-transparency: reduce. That is a user setting, not a theme, so the Light and Dark columns show the normal values and the override sits in its own column. It is not compared with Figma.

Composite values: --border-* and --blur-glass are shorthands, shown whole and marked composite. Comma and paren values (fonts, clamp(), cubic-bezier(), rgba()) are kept intact.

Not listed: --resume-url (URL string, not a design token).

Unused: 54 tokens below are flagged because nothing outside tokens.css references them and no other token aliases them; the excluded URL token is also unused.

SigmaMD: a Figma mode kept for display only; it is shown, never compared.
