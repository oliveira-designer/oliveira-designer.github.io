Hope Design System

Documentation

Reference for the Hope tokens and components, built from the real files in this repository. Audience for now: the owner and agents.

Sources of truth

  • Figma is canonical for token and component values.
  • This repository is canonical for prose, rules and the changelog (design-organization/GOVERNANCE.md, section 7).
  • These pages create no second source: they link css/tokens.css, css/components.css and the other site stylesheets directly, and the tokens page is generated from css/tokens.css.

Pages

  • Tokens: 163 tokens with Light and Dark values, 22 flagged as unused. Figma sync: 128 match, 2 mismatch, 1 accepted, 31 no Figma mapping, 0 no CSS token.
  • Components: Button (with Icon Button), Badge and Link, documented as they are in Figma and in code today. Run npm run docs:components to regenerate.

Commands

  • npm run docs:tokens regenerates docs/tokens.html, docs/data/tokens.json and this page.
  • npm run docs:components regenerates docs/components/*.html from docs/data/components-content.json, components-code-notes.json and components-map.json.
  • npm run docs:check fails if a demo uses a class missing from css/*.css, and lists CSS blocks that have no demo yet.
