04 · Motion

Funcional,
não decorativo.

Motion existe para comunicar mudança de estado, não para impressionar. Saída rápida (100ms), entrada generosa (250ms). Hover passa o mouse para ver — o sistema responde com a curva certa.

duration-fast
100ms · ease-out
Press, click, saídas. Resposta imediata sem ser brusca.
duration-normal
150ms · ease-out
Default para hover. Cor, background, border.
duration-slow
250ms · ease-out
Modais, popovers, entrada de elementos.
duration-deliberate
600ms · ease-in-out
Backgrounds atmosféricos. Momentos cinemáticos. Uso raro.
